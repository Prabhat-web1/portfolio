Real-time Vehicle Tracking System

Live · July 2026

A browser-based tracker that follows a vehicle on a map without anyone refreshing the page, and lets you replay where it has been.

  • Uses the browser's GPS and Socket.IO to push positions to every connected client in roughly 25 ms.
  • Stores location history in PostgreSQL through Prisma, then plays routes back on Leaflet.js.
  • Protects API routes with JWT authentication; the frontend is responsive for phones and desktops.

AI Paranormal Investigation Bot

Live · July 2026

A text classifier for paranormal narratives that is built to be questioned: every prediction comes with its evidence.

  • Sorts narratives into five categories with TF-IDF and SGDClassifier, at about 65% overall accuracy.
  • Returns class probabilities, a confidence score and the keywords that drove the call.
  • Llama 3.1 (via Groq) only rewrites the output in plain language. The classification stays deterministic, so the explanation can't invent facts.
